Batch at Scale

Technical Notes

  • • M4A uses AAC (lossy). For lossless, use WAV/FLAC.
  • • WAV/AIFF: pcm_s16le. OGG: Vorbis by default; Opus when compatible.
  • • All lossy formats use VBR for optimal quality/size ratio.
  • • Loop tags: OGG/FLAC/AIFF supported. Reads from M4A; cannot write to M4A.
